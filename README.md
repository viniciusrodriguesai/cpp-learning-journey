# C++ Learning Journey

Introductory C++ exercises from my learning process. This repository contains eight standalone examples covering variables, constants, operators, conditionals and Boolean expressions.

## Contents

- [`01-fundamentos`](01-fundamentos): variables, scope, arithmetic and increment/decrement operators.
- [`02-condicionais-e-loops`](02-condicionais-e-loops): conditional branches and logical operators.

Each source file has its own entry point. Compile and run one example at a time with a C++17 compiler:

```bash
g++ -std=c++17 -Wall -Wextra 01-fundamentos/ola_mundo.cpp -o hello
./hello
```

These are educational examples rather than a reusable library. Competitive programming exercises live in the separate [competitive-programming repository](https://github.com/viniciusrodriguesai/competitive-programming).
